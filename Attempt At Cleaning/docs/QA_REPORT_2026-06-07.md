### Stage 2 — P0 test isolation fixed (commits 6.31 + 6.32)

**P0-A** (`test_baseline_mode`, `test_coding_roles` — 9 tests):
`asyncio.get_event_loop().run_until_complete()` fails in Python 3.10+ after
any test that called `asyncio.run()`. Replaced all 9 occurrences with
`asyncio.run()`.

**P0-B** (`test_search_quality::test_enrich_replaces_snippet_with_page`):
`test_concurrency.py::_purge_core_modules()` deleted all `core.*` from
`sys.modules`, causing `_enrich_with_pages` to reimport a fresh `core.config`
with default `SEARCH_FETCH_MIN_CHARS=400`. The 230-char page text failed the
length gate since monkeypatch had only patched the stale module object.
Replaced `_purge_core_modules` with `importlib.reload()` (in-place update,
same object identity).
