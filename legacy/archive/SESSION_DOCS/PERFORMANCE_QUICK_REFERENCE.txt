KNOWN LIMITATIONS & TRADE-OFFS
================================================================================

1. Increasing semaphore limit:
   Trade-off: More VRAM usage (each generation ~2GB)
   Mitigate: Monitor VRAM, reduce if needed

2. Lazy embedding computation:
   Trade-off: First similarity check slightly slower
   Benefit: 60+ seconds saved per run

3. Removing sleep delays:
   Trade-off: May see race conditions in edge cases
   Benefit: 20-40% faster execution

4. Temporal filtering on similarity:
   Trade-off: May miss duplicates from >5 minutes ago
   Benefit: O(n) becomes O(recent signals)
